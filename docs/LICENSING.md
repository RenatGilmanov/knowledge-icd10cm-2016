# Licensing

No open-source license has yet been selected for the repository's original code, specification, documentation and visualization design. Public visibility on GitHub alone is not a general permission to reuse those materials. The repository owner can add the chosen license before publication and regenerate the release seal.

Source ICD-10-CM content and third-party software retain their own attribution and terms, as described in [NOTICE.md](../NOTICE.md). A future license for original project material must not be presented as a license grant over third-party source content.
